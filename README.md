# Hr-Analysis-Dashboard
Project: HR Analytics Dashboard Using Excel

Cleaned and analyzed employee data using Excel.

Created KPI cards and interactive dashboards using PivotTables and PivotCharts.

Analyzed employee attrition by department, age group, and overtime.

Used slicers to enable interactive filtering and support HR decision-making.
